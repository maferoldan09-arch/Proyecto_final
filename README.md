# KyneRun

KyneRun es un juego de plaaformas donde seguimos a un personaje llamado Ash, quien debe recorrer el mapa para conseguir un cofre con suministros de comida

## Características adicionales

- Parallax
- Plataforma movil
- Animación en Coleccionables y en menú principal

## Parallax

Un parallax sirve para darle profuncidad al fondo de un gamplay, poniendo capas en el eje Z donde se ponen varios dibujos a diferentes distancias y luego mediante el codigo, se iran moviendo a diferentes velocidades, dandole mayor realimso al movimiento, además de funcionar el loop, lo que hace que se repita el mismo fondo durante todo el nivel.

Usamos de guia un tutorial del programador KanarianDev
Link del video: https://www.youtube.com/watch?v=GmFGXzZALxs&t=183s

## Plataforma movil

La plataforma movil es una herramienta que le da más dinamismo al nivel, al implementar un sprite el cual tiene ciertas caracteristicas las cuales le permiten moverse, ya sea de forma vertical y horizontal, en nuestro caso particular, implementamos plataformas horizontales, que hacian más dinamica la experiencia del nivel.

Para hacer esto usamos de ayuda el tutorial del canal "Lucas Mode"
Link del video: https://www.youtube.com/watch?si=fHnnSlg4ZBQCMLTB&v=5MsT2_ypk44&feature=youtu.be&themeRefresh=1
